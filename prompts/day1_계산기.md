# Day 1 (10/18) — 계산기 최소 버전

CLAUDE.md와 data/README.md를 먼저 읽어줘.

오늘은 계산기 최소 버전을 만들 거야.
- src/index.html, src/app.js, src/style.css로 나눠서 만들 것
- data/weapons.csv와 data/armor.csv를 읽어서 쓸 것 (수치를 코드에 직접 적지 말 것)
- 입력: 무기 선택, 조끼 레벨(0~3)
- 출력: 몸통 1발 피해량, 필요 발수, TTK(ms)
- 무기 두 개를 나란히 비교할 수 있게 할 것
- 조끼 레벨을 바꾸면 전체 무기를 TTK 순으로 정렬한 표가 바뀌는 화면도 만들 것
- 각 수치 옆에 출처·패치(42.3)·검증 여부를 표시하고, verified=N이면 "미검증" 표시
- 화면 상단: "비공식 개인 프로젝트 · KRAFTON과 무관 · 42.3 기준 · 거리 감쇠·반동·명중률 미반영"
- O12는 비교 표에서 제외 (산탄/슬러그 계산이 달라서)
- TTK는 auto_fire=Y인 무기만 표시. 연사 모드가 없는 무기(DMR·SR 등)는 1발 피해량·필요 발수만 보여주고, TTK 정렬 표 대신 1발 피해량 순 표에 넣을 것
- VSS·MK14 EBR은 "연사 모드 기준" 표시를 붙여 TTK 표에 포함

시작하기 전에 계획을 5줄로 설명하고 내 확인을 받아.
