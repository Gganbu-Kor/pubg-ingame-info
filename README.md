# 게임 밖에서 찾던 정보를, 게임 안으로
PUBG 유저 편의성 개선 기획안 — 공식 API 데이터로 만든 인게임 정보 기능과 출시·측정 계획

> 개인이 작성한 가상 기획안이며 KRAFTON과 무관합니다. 게임 클라이언트에 접근하지 않고, 공식 PUBG API 데이터만 사용합니다.

- **시연:** [계산기 · 총기 가이드 · 내 최근 경기 · 컨셉 화면](https://gganbu-kor.github.io/pubg-ingame-info/src/index.html)
- **기획안 전문:** [docs/00_기획안.md](docs/00_기획안.md) · 결정 기록 [01](docs/01_의사결정기록.md) · AI 협업 로그 [02](docs/02_AI협업로그.md) · 검증 기록 [03](docs/03_검증기록.md) · 상황별 화면 [04](docs/04_상황별화면.md)
- **다른 프로젝트:** [맵 선호도에 안 보이는 것: 언제 봇이 판을 채우나](https://github.com/Gganbu-Kor/pubg-map-rotation) — 공식 API로 본 시간대별 봇 비율과 매칭 품질

## 무엇을 하나
- 무기·방어구(조끼·헬멧)·거리별로 13개 부위의 피해량, 필요 발수, TTK를 실루엣으로 표시 (43.2 기준)
- 닉네임으로 최근 경기를 불러와 나를 쓰러뜨린 총·부위·발수 표시
- 텔레메트리 실측으로 수치 검증 — 일반 경기 113개, 18,865발 중 99.7% 일치 · 부서진 조끼도 몸통 피해 20% 감소를 실측으로 발견 ([검증기록](docs/03_검증기록.md))
- 인게임 적용 컨셉과 출시·측정 계획 — 수류탄·화염병·여러 총·버튼이 생기지 않는 경우 등 실제 경기로 그린 상황별 화면 ([상황별 화면](docs/04_상황별화면.md))

## 실행
1. 웹 화면: VS Code에서 `src/index.html`을 Live Server로 열거나, 터미널에서 `python3 -m http.server --bind 127.0.0.1` 후 브라우저로 접속
2. 스크립트: `pip install -r requirements.txt` → `.env.example`을 `.env`로 복사해 키 입력 → `python scripts/파일명.py`

## 데이터 출처
- **원칙: 수치의 근거는 공식 PUBG API 실측.** 외부 출처는 텔레메트리로 검증한 값만 사용
- 기본 피해량·부위 배율·분류 배율·거리별 피해량·방어구 감소율: [pubgstatistics.com](https://pubgstatistics.com) (공식 API 기반 비공식 사이트, 43.2, 2026-10-20 조회)
  - 기본 피해량은 배틀그라운드 공식 카페 '광원효과' 님 게시글(42.3)과 28종 모두 일치
  - 거리별 피해량은 실측으로 범위 검사(경향)까지만 확인
- 연사력: 배틀그라운드 공식 카페 '광원효과' 님 게시글(42.3) — 실측 검증 안 됨
- 경기 데이터: PUBG 공식 API (내 경기 + 공식 무작위 경기 샘플)
