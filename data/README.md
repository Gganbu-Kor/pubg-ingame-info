# 데이터 규칙

## 피해량 계산 (10/20 변경)
- 1발 피해량 = 거리별 기본 피해량 × 부위 배율(hit_area) × 분류 배율(class_mult) × (1 − 방어구 감소율)
  - 부위 지정 없는 피격(텔레메트리 `NonSpecific`)은 예외: 실측상 기본 피해량 ×1.0 그대로 (계산기에는 표시하지 않음)
  - 방어구: 머리·목 = 헬멧, 쇄골·가슴·배·골반 = 조끼, 팔·다리 = 없음 (`hit_zones.csv`의 `armor_slot`)
- 수치 출처: **pubgstatistics.com** (공식 PUBG API 실제 피격 기록으로 계산한 비공식 사이트, 43.2 기준)
  - 작성자 결정 10/20. 숫자 값만 사용하고 출처·조회일을 표시. 사이트의 표 디자인·문구는 복사하지 않음
  - 다시 받기: `scripts/fetch_pgs_weapons.py` (원본은 `raw/pgs/`에 보관, 이미 받은 페이지는 다시 받지 않음)
- 다른 사이트의 데이터는 작성자가 승인한 곳만 가져온다. pubg.gs는 텔레메트리와 불일치해 사용하지 않음 (10/20)

## 파일
- `weapons.csv`: 0m 기본 피해량(base_damage), 연사력(rpm)
  - base_damage: pubgstatistics 0m 값. 28종 모두 기존 '광원효과' 님 표(42.3)와 같았음 → source에 함께 기록
  - O12는 사이트에 0m 값이 없어(2m부터) 기존 값 유지
  - (10/21 삭제) `body_mult`: 몸통 1개 기준 이전 계산식용 열. 분류 배율 `weapon_multipliers.csv`로 대체
  - `pgs_name`: pubgstatistics.com의 무기 이름 (수집 스크립트가 사용)
  - 10/20 추가 11종(DMR 5·SR 3·권총 3): 이름은 사이트 영어 이름, `auto_fire=N`(작성자 확인), 탄은 사이트 CSV(`ammo_source`에 표시)
    - 넣지 않은 것: 게임에서 삭제된 무기, 사이트 측정값 없는 무기
  - 10/20 추가 샷건 5종(DBS·S12K·S1897·S686·Sawed-off): `auto_fire=N`(작성자 확인), 탄은 기존 형식 `12게이지`
  - `pellets`: 샷건이 한 발에 쏘는 펠릿 수 (사이트 값, 수집 스크립트가 채움). 비어 있으면 1
    - 샷건의 `base_damage`·`falloff.csv`는 **펠릿 1개** 값. 한 발 피해량 = 펠릿 1개 × 펠릿 수 (전부 같은 부위 명중 가정)
    - O12는 슬러그탄(한 발 1개)이라 `pellets` 비어 있음. 연사 여부 미확인으로 계산 제외 상태
- `hit_zones.csv`: 13개 부위의 부위 배율(모든 무기 공통), 한국어 이름, 덮는 방어구
- `weapon_multipliers.csv`: 무기별·부위별 분류 배율. 대부분 같은 분류끼리 같지만 예외가 있어 무기별로 저장 (10/20)
  - 예외: Dragunov 머리·목 2.8 (다른 DMR 2.35, 작성자 확인 10/21). 수집 스크립트가 예외를 화면에 알려 줌
- `falloff.csv`: 무기별 거리별 기본 피해량. 사이트가 측정한 거리 지점만 있음 (그 사이 값은 추측하지 않음)
- `armor.csv`: 방어구 감소율. 사이트의 레벨별 피해량 ÷ 무방어 피해량으로 역산 (29종에서 일정함을 확인)
  - `vest,broken,0.20`: 부서진 조끼를 입고 있을 때 (텔레메트리 실측 64/64 + 작성자 확인, 10/21). 사이트에 없는 값이라 수집 스크립트가 지우지 않고 남김
  - `level`은 숫자(0~3) 또는 `broken`
- `verified` 규칙: 패치노트 원문 또는 텔레메트리 실측으로 확인한 값만 `Y`.
  - 10/20 작성자 승인: 텔레메트리 "확실"(정확 비교 일치 30발 이상·일치율 95% 이상) 판정인 무기·방어구 전 레벨을 `Y`로
  - 같은 기준으로 10/20 추가 무기 중 FAMAS·Kar98k·M24·Mini 14·SKS·SLR도 `Y`
- `weapons.csv`의 `auto_fire` (연사 모드 있음: Y / 없음: N / 비어 있음: 확인 필요)
  - 화면 표시: 1발 피해량·필요 발수는 모든 무기에 표시, **TTK는 `auto_fire=Y`인 무기만** 표시
  - DMR·SR은 기본적으로 연사로 쓰지 않으므로 N, rpm 칸은 비워도 됨
  - 예외: VSS·MK14 EBR은 연사 모드가 있어 Y → 화면에 "연사 모드 기준 TTK"로 표시
- `weapons.csv`의 탄 종류 열
  - `ammo`: 사용 탄 (`5.56mm`, `7.62mm`, `9mm`, `5.7mm`, `.45 ACP`, `.300 Magnum`, `12게이지` 형식). 가이드의 "탄 종류별" 정렬에 사용
  - `ammo_source`: `작성자 정리 (인게임 확인 필요)` = 초안 / `작성자 확인` = 인게임에서 확인함 / `pubgstatistics.com (조회일)` = 사이트 데이터
- `weapons.csv`의 난이도 열 (주관 정보 — 수치 검증 대상 아님)
  - `difficulty`: 쉬움 / 보통 / 어려움 중 하나. 비어 있으면 화면에 "미정"
  - `difficulty_reason`: 그렇게 판단한 이유 한 줄
  - `difficulty_source`: 지금은 `작성자 의견`. 추후 공식 카페 투표 결과로 바꾸면 `공식 카페 투표 (날짜, 참여 n명)` 형식
- `weapons.csv`의 묶음 열 (가이드 화면 전용 — 계산기에서는 따로 표시)
  - `guide_group`: 가이드에서 하나로 묶을 이름 (예: MG3 두 줄 모두 `MG3`). 비어 있으면 묶지 않음
  - `variant`: 묶음 안 선택 버튼 이름 (예: `660RPM`, `990RPM`)
  - CSV에서 먼저 나오는 줄이 기본 선택. 목록의 난이도·탄 종류도 기본 선택 줄 기준
- `weapons.csv`의 `api_id`: 텔레메트리 `damageCauserName` 값 (예: `WeapACE32_C`). "내 최근 경기"와 계산기를 연결
  - 출처: PUBG 공식 GitHub `pubg/api-assets`의 damageCauserName 사전
  - 한 무기에 ID가 여러 개면 `|`로 구분 (M416·AKM은 스킨 버전으로 보이는 ID가 따로 있음)
  - FAMAS(`WeapFamasG2_C`)·RPD(`WeapRPD_C`)는 공식 사전에 없는 ID. 작성자 승인 10/20으로 등록
    (FAMAS는 실측 49발 중 49발 일치로 확인, RPD는 감쇠가 0m부터라 이름 기준)
- `settings.csv`: 분석 설정값
  - `engagement_gap_sec`: "쓰러뜨린 공격"을 묶을 때, 맞은 공격 사이 공백이 이 값(초)보다 길면 다른 교전으로 보고 끊음
- `my_match_summary.json`: `scripts/analyze_my_match.py`가 만드는 결과. 내 닉네임 외 다른 플레이어 정보 없음
- `classes.csv`: 총기 분류별 역할 안내 (신규 유저용, 작성자 확정 10/21)
  - `range`(쓰는 거리)·`role`(역할)·`tip`(팁): 공식 사이트 분류 소개 문구 기반 + 작성자 정리. 거리 용어는 공식에 맞춤(원거리 → 장거리). 계산값이 아님
  - `official_desc`: pubg.com 무기 페이지의 분류 소개 문구 원문(앞의 "분류명(약자)은 "만 뺌, 조회 2026-10-21). 인벤토리 툴팁 "용도" 칸에 사용
  - LMG는 공식 사이트에서 "기타" 탭이라 공식 문구가 없음 → 작성자 문구 사용
- `verify_damage_summary.csv`: `scripts/verify_damage.py` 결과. 무기별 정확 비교 표본·일치·레벨 다름·불일치, 감쇠 구간 범위 검사
  - 계산기 화면 하단의 "실제 경기 n발 중 m% 일치" 문구가 이 파일을 읽음
- `verify_zone_map.csv`: 텔레메트리 부위 기록(HeadShot 등) ↔ 실측으로 맞은 13개 세부 부위
- `settings.csv`의 `verify_match_types`: 검증에 쓰는 경기 유형 (`|`로 여러 개). 지금은 `official`만
- `settings.csv`의 `card_damage_categories`: 부위 실루엣·발수로 그리는 피해 종류 (`;`로 여러 개). 부위가 기록되는 공격(총·근접 무기·주먹·발차기)만. 그 밖의 피해(수류탄·화염병·블루존 수류탄 등)는 원인별 피해 합계로만 표시 (10/23)
- `settings.csv`의 `same_moment_sec`: 한 번에 여러 적을 맞혔을 때(수류탄 등) "같은 순간"으로 보는 시간. 그중 그 교전에서 피해를 가장 많이 준 적을 "내가 공격하던 적"으로 고름 (10/23)
- `damage_causes.csv`: 부위가 남지 않는 피해의 화면 이름 (category → name_ko). 공식 한국어 이름이 확실하지 않은 것은 영어로 둠 (10/18 원칙)
- `raw/`: API에서 받은 원본(용량이 크므로 git에 올리지 않음).
  - `raw/samples/`: 공식 무작위 경기(`scripts/fetch_samples.py`). 피격·장착·조끼 파괴 기록만, 닉네임 삭제, 계정 ID는 경기 안 임의 번호
- `weapon_range_baseline.csv`: 총 분류별 실제로 맞힌 거리(교전마다 첫 명중, 중앙값·가운데 50%). 출시 후 "신규 유저가 총을 맞는 거리에서 쓰게 됐는가"를 잴 내부 기준. 화면에 보여 주는 값이 아님 (`scripts/weapon_range_baseline.py`, 10/23)
