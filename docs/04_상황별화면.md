# 상황별 화면 — "쓰러진 공격" 카드·매치 리포트

기획안 3장 ①(결과 화면 카드)과 ①-2(로비 전적 매치 리포트)가 여러 상황에서 어떻게 보이는지 모은 문서입니다.
모든 화면은 **지원자의 실제 일반 경기**(공식 PUBG API 기록)로 그렸습니다. 상대는 "상대1·상대2"로 익명 처리했습니다.
이미지는 `docs/images/`에 있고, 같은 화면은 `src/concept.html?frame=1b&ex=경기ID`(카드)·`frame=1c&ex=경기ID`(매치 리포트)로 다시 그릴 수 있습니다.

_개인 컨셉 목업이며 KRAFTON과 무관합니다._

## 실제 경기에 없어 화면을 남기지 않은 상황

| 상황 | 화면 규칙 | 근거 |
|---|---|---|
| 한 번에 여러 적에게 피해 (수류탄 등) | 같은 순간(1초 안) 맞은 적 중 이 교전에서 피해를 가장 많이 준 적을 대표로, 카드에는 "외 N명에게도 피해 · 합계 X". 매치 리포트에는 피해를 준 적 모두 | 지원자 경기 13개의 수류탄 폭발 280번 중 30번(11%)이 2명 이상 (`03_검증기록.md`). 지원자가 쓰러진 12회에는 없었음. 임시 시험 데이터로 화면이 깨지지 않는 것만 확인했고, 지어낸 기록이라 이미지는 남기지 않음 |
| 블루존·낙하 등 다른 플레이어가 주지 않은 피해로만 쓰러짐 | 다루지 않음 (버튼 없음) | 분석은 다른 플레이어가 준 피해만 모음 |
| 이벤트 모드(좀비 모드 등) | 분석하지 않음 | 무기·피해 규칙이 달라 제외 (지원자 결정 10/23, `data/settings.csv`의 `verify_match_types`) |
